# Syntecxhub Port Scanner

 Description
This project is a TCP Port Scanner developed in Python as part of the Syntecxhub Internship Program. It scans a target host for open and closed ports using socket programming and multithreading.

 Features
- Scan a single host
- Custom port range
- Multithreaded scanning
- Logs results to a file
- Handles exceptions gracefully
 Technologies Used
- Python
- socket
- threading

 How to Run
1. Clone the repository
2. Run the script using:python port_scanner.py
3. Enter target IP/hostname and port range

 Output
- Displays open and closed ports
- Saves results in `scan_results.txt`
